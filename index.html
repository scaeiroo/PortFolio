EXPEDIENTE Nº 01

Pipeline ETL + Planificador de Producción + Visualización Dual

Sistema integral de análisis de producción industrial

[ + ]

Problema: una planta industrial necesitaba centralizar datos de producción dispersos entre un sistema de planta (MES) y un ERP, limpiarlos y visualizarlos en tiempo real tanto para operarios como para dirección.

Fase A · ETL: scripts programados vía cron con extracción incremental desde SQL Server, deduplicación con lógica de priorización por incidencias, fechas y cantidades, carga centralizada en MySQL y alertas automáticas por correo ante fallos en cualquier etapa.

Fase B · Planificador: motor de recálculo de fechas que respeta calendarios laborales distintos por máquina, aplica márgenes configurables por el propio equipo vía Excel, y encadena órdenes en cascada según prioridad.

Fase C · Visualización dual: panel en Grafana con el plano interactivo de la planta (HTML/SVG embebido) donde cada máquina cambia de color según su estado en tiempo real; además de dos dashboards en Power BI con modelo en estrella y medidas DAX — uno de análisis operativo (líneas, operarios, incidencias, OEE) y otro dedicado al planificador (por máquina, prioridad y desviaciones).

EXPEDIENTE Nº 02

Motor de Recomendación de Productos

Sistema híbrido de recomendación para equipo comercial B2B

[ + ]

Problema: el equipo comercial necesitaba sugerencias de producto personalizadas por cliente, sin depender únicamente de la intuición del comercial de turno.

Enfoque híbrido: combina el perfil individual de cada cliente (categorías y rango de precio habituales) con filtrado colaborativo, que detecta patrones entre clientes con comportamientos de compra similares. El filtrado colaborativo es el factor con mayor peso en la puntuación final, seguido por las categorías ya conocidas del cliente, la similitud textual entre productos, la señal geográfica, el precio preferido y la novedad.

Pipeline en 5 pasos: extracción desde Oracle → limpieza y segmentación por franja de precio → modelado de perfiles individuales → filtrado colaborativo → generación de puntuación y ranking final por categoría.

Escala: procesa un histórico amplio de transacciones y una base de clientes activos considerable, generando recomendaciones diferenciadas por segmento (hostelería, doméstico, online).

EXPEDIENTE Nº 03

Cliente Git con Sincronización Segura On-Premise

Herramienta de escritorio para versionar y respaldar datos sin depender de la nube

[ + ]

Problema: necesidad de un flujo de trabajo tipo GitHub pero sobre un servidor propio en red local, para poder versionar y respaldar datos sin depender de un servicio en la nube.

Solución: interfaz de escritorio que gestiona repositorios remotos vía SSH, con autenticación no interactiva usuario + contraseña mediante scripts temporales de tipo SSH_ASKPASS que se generan, se usan y se destruyen en el mismo ciclo, sin persistir credenciales en disco. Incluye sincronización automática de los archivos de trabajo vía SCP tras cada operación de subida o descarga de cambios.

Detalles técnicos: gestión de estado del repositorio, historial de commits desde la propia interfaz, y empaquetado como ejecutable independiente para distribuirlo sin requerir un entorno Python instalado.
